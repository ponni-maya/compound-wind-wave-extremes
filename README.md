### 🔬 Current Project — Compound Wind–Wave Extremes

A multi-stage analysis pipeline moving from raw clustered climate data to publication-ready extreme-risk diagnostics:

| Stage | Focus | Key methods |
|---|---|---|
| 01 | Frequency & intensity of compound extremes | Joint exceedance probability (P95∩P95), threshold sensitivity |
| 02 | Model consistency & bias in extreme tails | GPD fitting, percentile comparison, Taylor diagrams |
| 03 | Dependence structure of joint extremes | Kendall's τ, empirical tail dependence, Gaussian copulas |
| 04 | Temporal persistence & downtime | Run-length statistics, Downtime Risk Index (spatial) |
| 05 | Extreme–mean coupling & intermittency | EMCR (p95/mean) across regimes and variables |
| 07 | Joint design return levels | Copula-based return level contours, model bias in design values |
| 08 | Synthesis across regimes | Cross-metric summary heatmaps, ERA5 vs. model deltas |

Each stage compares **reanalysis vs. scenario/high-resolution model output** across nine wind–wave regimes, quantifying how well models reproduce not just means but the *shape, dependence, and persistence of extremes* — a core question in impacts and compound-risk research.
